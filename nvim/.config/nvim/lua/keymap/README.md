# Описание keymap-ов

## lsp-buf-keymap

| Маппинг           | Действие              | Мнемоника                 | Описание |
|-------------------|-----------------------|---------------------------|----------|
| **Навигация**     |
| `<leader>gd`      | definition            | definition                | Прыжок туда, где символ определён — тело функции, класс, переменная. Работает через файлы. Назад — <C-t> |
| `<leader>gD`      | declaration           | Declaration (пара к gd)   | Прыжок к объявлению, а не к реализации: сигнатура в .h, interface, .pyi, forward-объявление. В языках без разделения часто совпадает с gd |
| `<leader>gr`      | references            | references                | Все места, где символ используется. Список кладётся в quickfix: :cnext / :cprev, посмотреть целиком — :copen |
| `<leader>gi`      | implementation        | implementation            | К реализациям интерфейса или абстрактного метода. Полезно в Go, TS, Java, C++; в Python обычно бесполезно |
| `<leader>gy`      | type definition       | type (gt занят табами)    | К определению типа символа, а не самого символа: стоя на переменной user, попадёшь в класс User |
| `<leader>gs`      | document symbols      | symbols                   | Оглавление текущего файла: функции, классы, методы. Список → quickfix. Удобно для навигации по большому файлу |
| `<leader>gw`      | workspace symbols     | workspace                 | Поиск символа по имени во всём проекте. Запрашивает строку поиска, результат → quickfix |
| `<leader>gh`      | hover                 | hover                     | Всплывающее окно с типом и документацией под курсором. То же самое, что K — просто альтернатива с leader |
| **Действия**      |
| `<leader>ga`      | code action           | action                    | Меню предложений сервера: «добавить импорт», «убрать неиспользуемое», «извлечь в функцию», быстрые фиксы диагностики. В visual-режиме — действия для выделения |
| `<leader>gn`      | rename                | name (r занят references) | Переименовать символ во всех файлах проекта с учётом области видимости — не тупой поиск-замена. Открывает запрос нового имени |
| `<leader>gf`      | format                | format                    | Отформатировать весь буфер через LSP. В visual-режиме — только выделенный диапазон (если сервер умеет rangeFormatting) |
| **Диагностика**   |
| `<leader>ge`      | line diagnostics      | error                     | Полный текст ошибок/предупреждений текущей строки во всплывающем окне — когда виртуальный текст обрезан или их несколько |
| `<leader>gq`      | diagnostics → loclist | quickfix                  | Все диагностики буфера списком в location list: :lopen, :lnext / :lprev. Удобно вычищать файл по списку |
| **Insert-режим**  |
| `<Ctrl-Space>`    | completion            | стандарт IDE              | Принудительно запросить у сервера список автодополнений в текущей позиции. Нужно, когда меню не всплыло само: autotrigger срабатывает только на trigger-символах (., :, () или после определённых условий|
